# مكتبتنا

تطبيق موبايل لأرشفة وتنظيم مكتبة البيت: كل كتاب شو هو، ووين موجود بالضبط (الغرفة، والمكتبة، والقسم، والرف)، مع عرض 3D للمكتبات.

- المرجع الكامل للمشروع وكل القرارات: [`docs/PROJECT_BRIEF.md`](docs/PROJECT_BRIEF.md)
- التقنيات: React Native (Expo) + SQLite محلي، وNestJS + PostgreSQL على لابتوب بالبيت، ومزامنة offline-first عبر Tailscale.
